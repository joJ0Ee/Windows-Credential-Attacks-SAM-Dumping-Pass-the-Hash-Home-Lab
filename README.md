## Scenario Overview

As a Security Operations Center (SOC) Analyst, understanding how attacks leave footprints in system logs requires executing the attack lifecycle end-to-end. This lab demonstrates dumping NTLM password hashes from a local Windows system, cracking the hash offline, reusing credentials remotely, executing a **Pass-the-Hash (PtH)** attack to gain shell access, and ultimately analyzing the resulting security telemetry inside the Windows Security Event Log.
